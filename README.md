# DSAI3301 Project – FutureFrame

This repository contains the implementation for my DSAI3301 course project. It performs data cleaning, exploratory analysis, and statistical modeling on population indicators, as well as a dashboard.

## Features
- Time series forecasting with ARIMA and Holt-Winters models.  
- Seasonal decomposition and stationarity testing (ADF test).  
- Evaluation metrics: MAE, MSE, R².  
- Autocorrelation and partial autocorrelation plotting.  
- Data analysis and visualization with Pandas, Matplotlib, and Seaborn.  
- Statistical modeling with Statsmodels and Scipy.
- Visualization with PowerBI dashboard.

## Requirements
Install the following Python libraries:

- `numpy`  
- `pandas`  
- `matplotlib`  
- `seaborn`  
- `scipy`  
- `statsmodels`  
- `scikit-learn`
